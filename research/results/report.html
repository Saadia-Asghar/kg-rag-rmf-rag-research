RMF-RAG: does curved graph space improve retrieval?

A small, honest experiment on the Kaggle disease–drug dataset. We hide one known drug link, train two graph embedding models, and measure whether the correct drug is recovered in the ranked results.

1,000Kaggle source rows
880unique disease–drug pairs
698training graph links
19recoverable test queries
What this proves: a measurable retrieval comparison on a real public dataset. What it does not prove: that the method solves gene→disease→drug reasoning. This Kaggle source has no gene edges, so that claim needs a second biomedical knowledge graph benchmark.

Recall@k means “the correct held-out drug appeared in the first k results.” MRR rewards a correct answer appearing near the top. Graph grounded means the top prediction had a ≤3-hop path in the training graph.

What the model is doing

We turn each record into a small graph: disease → shared disease-name token → drug. For example, diseases that share meaningful words create reusable paths to drugs. The Euclidean model learns flat distances. RMF-RAG learns the same graph with Poincaré-ball distances, where the boundary gives more room to represent branching structure.

The test set contains only held-out links that remain reachable through another disease sharing a token with the target drug. That avoids scoring impossible queries as model failures.

Reproduce it

From the workspace root:

python research/scripts/run_rmf_rag_experiment.py

Outputs: research/results/metrics.json, predictions.csv, and this report. The source citation and dataset limitation are recorded in research/data/SOURCE.md.

Paper-ready limitations

  • The dataset is a disease→drug recommendation collection, not a curated gene–disease–drug KG.
  • The graph contains disease-name token bridges that are an experimental construction, not ground-truth biomedical relations.
  • This is a CPU-friendly pilot with a small embedding dimension and a held-out-link protocol; report it as preliminary evidence.
  • A stronger paper should add PrimeKG, Hetionet, Bio2RDF, or another licensed biomedical KG and include 2-hop/3-hop answer-path annotations.
